Student Performance Analyzer

This challenge is all about implementing basic Student Performance Analyzer by using lists and to manage multiple student marks

The program:
1.Accepts multiple student marks as input.
2.Applies bonus marks based on registration number parity.
3.Validates marks.
4.Categorizes student performance.
5.Displays total valid students and total failed students.

Performance Classification:
Marks     Range Category
90 – 100  Excellent
75 – 89   Very Good
60 – 74   Good
40 – 59   Average
0 – 39    Fail
<0 or >100 Invalid

Personlisation logic used-
- If registration number is **odd** → Add **7 marks** (for marks between 30 and 90).
- If registration number is **even** → Add **5 marks** (for marks between 30 and 90).

How to run program download file and open it in command prompt or pycharm or others then run it
