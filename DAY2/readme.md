 Smart Registration System
 
 This challenge is all about learning string operations and implementing basic operations on Smart Registration System.

 Validation Rules Implemented:
 1.	Student ID: 7 characters → CSE- + 3 digits
 2.	Email: one @, ends with .edu
 3.	Password: minimum 8 characters, starts with capital letter, has at least one number
 4.	Referral code: REF + 2 digits + @

 How to run code-
 Download the file DAY2 and then open in command prompt or vs-code then run it
