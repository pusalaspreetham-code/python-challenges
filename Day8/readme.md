# Multi-Dimensional Academic Intelligence System

##  Overview
This project analyzes student performance using marks, attendance, and assignment scores.  
It uses Python, Pandas, and NumPy to generate data, classify students, and produce insights.

---

## ⚙️ Logic Used
- Generate student data using `random`
- Store data in list → convert to DataFrame
- Classify students into categories (At Risk, Average, Good, Top Performer)
- Calculate mean, median, and standard deviation using NumPy
- Normalize marks manually
- Create a performance index using marks, assignment, and attendance
- Detect patterns like consistency and risk
- Display final system insight

---

## 🎯 Personalization Logic
- Last digit of Register Number = **1**
- So, 10 students are generated

Reason: Makes the dataset unique and personalized.

---

## 📊 Output
- DataFrame table
- Student categories
- Statistical summary
- Final insight
